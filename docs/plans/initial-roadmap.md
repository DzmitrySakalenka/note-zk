# Initial Roadmap

## Phase 0: Design

- define note schema
- define local index schema
- define sync model
- define crate boundaries

## Phase 1: Local-Only MVP

- scan vault
- parse markdown notes
- store metadata in SQLite
- expose CLI commands
- support search and backlinks

## Phase 2: AI Indexing

- chunk notes
- generate embeddings
- semantic search
- provider abstraction

## Phase 3: Remote Sync

- server API
- auth
- push/pull sync
- mirrored vault behavior
- conflict handling

## Phase 4: Editor Clients

- VS Code extension
- Neovim plugin
- command flows for search/open/create/sync/chat

## Phase 5: Higher-Level Features

- wiki synthesis
- chat over scoped notes
- graph exploration
- feed/import workflows
